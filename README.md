# SUKHA English website

Buildless static website. Served files are in `dist/`.

Content generator: `python3 scripts/build-content.py`. This rewrites HTML, robots.txt and sitemap.xml; CSS and JavaScript are maintained separately in dist/style.css and dist/app.js.

This is an owner-private design preview. Forms create local summaries only, with no network submission or persistence. Do not enable live inquiries until business identity, verified products, contact destination and privacy terms have been supplied and approved in scope.

Keep the existing .openai/hosting.json project identity. Abstract artwork is editorial, not product photography. Do not fabricate trains, vessels, cabins, inventory, reviews or staff.
